# Interface fonts

Noto Sans Regular and SemiBold, from the Noto project:
https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans

Distributed under the SIL Open Font License in OFL.txt.
Regular is used for body text, semibold for headings. The UI atlas includes
Latin Extended and general punctuation; untranslated interface languages fall
back to English. These fonts do not provide Japanese or Chinese game-title glyphs.

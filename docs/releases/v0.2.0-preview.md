# PS5X360 v0.2.0-preview — development build

## Changes

- Cover flow now projects rotated 3D cases, including their tops and spines.
  Full inserts retain their actual spine artwork; front-only images use a
  plastic edge. Subdivided textures reduce affine perspective distortion.
- No-frame diagnostics also cover games stuck before their first frame.
  Short log captures and thread snapshots stop automatically; rendering
  recovery clears the translated notice.
- The library warns about Garden Warfare's unavailable online authentication.

## Installation

Extract `PS5X360-v0.2.0-preview.zip` and copy the complete `PPSA50011` folder
to `/data/homebrew/PPSA50011` in your existing homebrew environment. Close
the application before updating, and reopen it afterward. Preserve your games
in separate folders under `PPSA50011/assets/roms/`.

See [Installation and usage](https://github.com/BrinooTk/PS5X360/blob/main/docs/INSTALLATION.md).

## Verification and limits

The native application compiled and passed executable image validation.
Regression checks cover initial zero-frame loading, bounded capture, recovery
and finite case projection. The actual launcher draw list was rendered locally
with generated grid inserts and visually inspected for box depth and texture
continuity. The executable was installed on the development console and verified
through FTP, with the previous executable retained. Console gameplay and final
appearance require a new hardware run of this exact build.

**Garden Warfare has not been reproduced locally or fixed.** The game depends
on online services; the emulator does not implement Xbox Live/EA authentication.
Zero FPS alone cannot distinguish online waiting from an emulator defect.
This is an improvement to diagnostics, not a universal loading-freeze fix.

Burst Limit and Ultimate Tenkaichi fight black screens remain unresolved.
Community patches ship disabled. No games, BIOS or keys are included.

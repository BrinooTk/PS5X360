# PS5X360 v0.3.0-preview — development build

## Changes

- Logs are created automatically for each game launch in
  `/download0/xbox360ps5/LOGS`, including launch errors and native crash reports.
  Filenames contain the game's name and UTC timestamp; headers identify the
  build, source and title ID. Existing sessions are preserved. Verbose sessions
  retain their initial segment and three rotating 8 MiB segments.
- **Settings → Game folders** lets you add and remove multiple search locations
  using the controller. The folder picker supports any directory visible to the
  application, including external devices. Unavailable locations remain saved;
  overlapping locations do not duplicate games.
- `python tools/console.py game-logs --host YOUR_PS5_IP` downloads mounted log
  files and creates a shareable ZIP. Keep the emulator open during download.

## Installation

Extract `PS5X360-v0.3.0-preview.zip` and copy the complete `PPSA50011` folder
to `/data/homebrew/PPSA50011` in your existing homebrew environment. Close
the application before updating and reopen it afterward. Preserve your games.
See [Installation and usage](https://github.com/BrinooTk/PS5X360/blob/main/docs/INSTALLATION.md).

## Verification and limits

Storage regression tests cover path normalization, offline-path persistence,
session isolation, concurrent writes, rotation and failure fallback. The host
launcher checks overlapping roots using generated fixtures and renders the new
panels, which were visually inspected. The native build compiled, passed
executable image validation and was installed on the development PS5 with FTP
verification and a backup of the prior executable. The FTP downloader retrieved the previous build's
mounted logs and created a ZIP; new per-game files require reopening this build
and launching a title. External-drive access depends on the mounts
visible to the title, not just on the folder configuration.

This feature does not fix Garden Warfare online authentication or the unresolved
Burst Limit/Ultimate Tenkaichi fight black screens. Community patches ship
disabled. No games, BIOS or keys are included.

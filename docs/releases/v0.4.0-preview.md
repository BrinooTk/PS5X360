# PS5X360 v0.4.0-preview — development build

## Changes

- **Settings → VSync** now offers a saved On/Off choice. A changed value
  automatically restarts the emulator when the settings panel closes, so it
  is applied before Canary initializes its frame limiter. Default: On.
- The library follows the supplied Aurora cover-flow reference with a larger
  central cover, parallel fronts, overlapping neighbours and reflections.

## Installation

Extract `PS5X360-v0.4.0-preview.zip` and copy the complete `PPSA50011` folder
to `/data/homebrew/PPSA50011` in your working homebrew environment. Close the
emulator before updating and reopen it afterward. Preserve your games.

## Verification and limits

Host checks verify that disabling VSync persists, requests a restart and does
not mutate the live core flag. Reverting the choice cancels the pending restart.
Cover checks verify front alignment, decreasing size, overlap and finite
projection. The actual launcher draw list is rendered with test inserts for
visual inspection. The native application compiled, passed image validation
and was installed on the development PS5 with FTP verification and the previous
executable retained. Final appearance and game timing require a new hardware run.

This setting controls emulated VSync, not PS5 display synchronization. Disabling
it is not a universal compatibility fix or an FPS guarantee. Existing online
authentication and fight-rendering limitations remain as documented.

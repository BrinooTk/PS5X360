# PS5X360 v0.4.1-preview — development build

## Changes

Library duplicate detection now uses complete normalized absolute source paths,
avoiding native realpath identity resolution. Games with the same executable
filename in different folders remain separate. Repeated or overlapping sources
still deduplicate. Scan logs include discovered paths and directory errors.

## Installation

Preserve your games and configuration. Close the emulator, copy the supplied
`PPSA50011` application folder to `/data/homebrew/PPSA50011`, and reopen it.

## Verification

The reported console showed one game with the All filter, while FTP listed eight
game folders. A host regression checks seven different `default.xex` paths with
overlapping and normalized roots. Final console count requires reopening the
updated title and inspecting its new launcher log.

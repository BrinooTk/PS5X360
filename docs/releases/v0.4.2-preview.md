# PS5X360 v0.4.2-preview — development build

Logs prefer `/data/homebrew/PPSA50011/logs`, then its title-mounted `/app0/logs`
alias. A new file is created for each game session with the game's name, source
key and UTC timestamp. The header records title ID, game path and build version.
The first segment is preserved and three additional segments rotate at 8 MiB.

If the title cannot write to the installation mount, it retains per-game logs
in persistent sandbox storage. Running `tools/Download PS5 logs.bat` retrieves
those files, exports them to the installation's `logs` folder through FTP and
creates a shareable ZIP on the computer. It also reads logs already in that
folder when the title is closed. Legacy boot/engine files receive a sandbox
prefix. Existing games and saved configurations are preserved.

The writable path selected on the development PS5 requires a fresh launch to
verify. File/package checks do not establish firmware or game compatibility.

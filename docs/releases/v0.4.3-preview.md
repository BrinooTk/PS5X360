# PS5X360 v0.4.3-preview — development build

## General compatibility correction

Native and host startup now mount writable `cache:`, `cache0:` and `cache1:`
guest devices, matching the initialization performed by Canary's desktop
frontend. The custom startup previously omitted these mounts. A real GTA IV
session from v0.4.2 reported device-not-found while opening `cache:\valid.txt`
and `cache1:\valid.txt`.

Files live under `/download0/xbox360ps5/utility-cache` on the PS5, separate from
the shader cache, game files and saves. Failed cache initialization is logged
and cancels launch rather than continuing with missing devices.

## Verification

The host VFS check reproduces the missing device before initialization, writes
different data to the same guest filename on all three devices, then remounts
and reads it back. This verifies the general filesystem correction. It does
not establish that missing cache was the only GTA IV loading blocker, guarantee
60 FPS, or validate firmware 10.20/11.60. Real game results remain separate.

## Installation

Preserve games and saved configuration. Close PS5X360, update the complete
`PPSA50011` application folder and reopen it. Game-session logs include the
emulator version and source path.

# PS5X360 v0.4.4-preview — development build

## Logging overhead correction

Normal gameplay records session metadata, warnings and errors rather than
continuous informational filesystem and debug GPU/kernel traces. Platform
stdout duplication is disabled; per-game files and the existing network sink
remain available. An old debug sentinel no longer overrides the visible setting.

On the first run after updating, detailed logging is disabled once. Future
explicit choices in Settings persist. The bounded stall diagnostic still
temporarily enables tracing to capture a stopped game. Gameplay settings,
utility cache mounts, games and saves are retained.

These changes address observed log volume and redundant output. Recovery from
reported 6–15 FPS requires a new hardware measurement; no universal FPS claim
is made. The prior utility-cache correction was verified on the PS5. GTA IV
also reached its opening 3D cutscene in a 90-second host run, with visible
rendering defects, not evidence of completed gameplay compatibility.

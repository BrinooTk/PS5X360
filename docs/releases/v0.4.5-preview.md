# PS5X360 v0.4.5-preview — development build

## Shared patch integration

The native Canary core now consumes the patch selections saved by the launcher,
before JIT precompilation and guest execution. Previously the menu used a separate
choice store that the Canary patcher did not read. This correction applies to all
titles, including dynamically loaded XEX modules. The standard Canary patcher is
retained in binaries without this integration.

Executable hashes come directly from Canary and are recorded in the library.
Only files matching the executable hash can be applied. Logs include the hash,
version mismatches, verified writes, failures and applied patch names. Invalid
or uncommitted writes are rejected before any patch bytes are changed.

GTA IV's community Unlock FPS patch requires emulated VSync to be disabled in
Settings, followed by a restart. An unlocked frame rate is not a performance
upgrade: demanding scenes can still fall below 60 FPS. Translation modifications
and title updates can change the executable hash; do not force another version's
patch onto them. The default VSync preference is retained.

The prior normal-logging correction and utility-cache mounts are retained.
Hardware gameplay performance still requires measurements in the affected scenes.

## Verification

Host tests using the supplied GTA IV executable (`4CBE7EEB2455A159`):
Unlock FPS enabled applied one verified write; disabled applied none; an incorrect
hash applied none; an uncommitted address was rejected and applied none. The PS5
image passed address, load-segment and relocation validation. These checks do not
measure hardware gameplay FPS.

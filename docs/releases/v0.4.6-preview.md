# PS5X360 v0.4.6-preview -- development build

Fix an observed startup abort in profile loading. The hardware stack identified
ContentPackageDirectory teardown calling ExtractContentHeader, whose throwing
filesystem operations escaped a noexcept destructor. Header updates now return
an error status, write the full padded header to a temporary file and replace the
old header only after a successful write. Failures are logged with the path and
error. Existing profiles and saves are retained.

Early boot and fatal-signal diagnostics now prefer /app0/logs/boot.log, visible
through FTP at /data/homebrew/PPSA50011/logs/boot.log. Sandbox logging remains a
fallback. Patch integration from 0.4.5 and the normal logging policy are retained.

Hardware startup requires a new launch to confirm the correction.

Verification: host regression passed header creation, repeated updates, invalid
parent paths and replacement failures, preserving previous data without throwing.
The GTA IV patch integration regression still applied Unlock FPS. Native image
validation passed. A new hardware launch is needed to confirm startup.

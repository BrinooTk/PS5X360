# PS5X360 v0.4.7-preview -- development build

## Patch selection and requirements

Filter patch files by executable hash before merging duplicate names. The menu
and runtime share the same deterministic selection. Duplicate names and identical
write lists appear once. Conflicting writes from enabled patches are rejected
before changing memory; enabling a conflicting choice in the menu disables the
previous choice. Version hashes remain mandatory at execution.

An applied patch explicitly requiring disabled VSync now sets a per-title atomic
override. Native frame pacing recomputes its period when the override changes,
without altering the saved preference. The next main executable resets this
state. No override is activated for rejected or disabled patches.

GTA IV hardware logs confirmed Unlock FPS was applied while emulated VSync was
still on, and a 30-second interval reached a minimum of 18 FPS. This build fixes
the unmet patch prerequisite; it does not establish constant 60 FPS or resolve
unmeasured CPU/GPU bottlenecks in demanding gameplay scenes.

The profile-header startup correction and normal logging policy are retained.

Verification: selection regression passed version-before-dedup and overlap checks.
A GTA IV host run with duplicate definitions and a conflicting third patch applied
Unlock FPS once, rejected the conflicting writes and rejected the TU8 hash. The
per-title override flag reset test passed. Native image validation passed, and
the linked GPU pacing worker uses the same atomic override as the patch handler.
A fresh PS5 gameplay run is required to measure FPS after the update.

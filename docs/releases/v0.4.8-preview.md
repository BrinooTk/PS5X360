# PS5X360 v0.4.8-preview — development build

## General compatibility and diagnostics

- Resolve relative module paths with subdirectories against the current executable's directory. Qualified device paths retain their meaning. Initial loads no longer dereference an empty module list.
- Query loaded module names before filesystem resolution. Missing bare-name handle queries return not-found without attempting to resolve a device-less path. This addresses misleading WavesLibDLL lookup errors seen in Halo 3 logs; it does not manufacture missing DLLs or establish Halo 3 gameplay compatibility.
- Preserve ENOSPC from buffered save-header writes and return disk-full rather than a generic failure. Existing headers remain intact. Logs include the affected save destination and available space. No saves, profiles or caches are deleted, and this change does not expand an already full download container.
- FPS and no-output diagnostics use successful Vulkan guest-output refreshes. Submitted swap requests are logged separately. Refresh counts are renderer output activity, not an independently measured physical display refresh rate. No command timing or VSync preference is changed.
- Boot diagnostics identify the build. Memory reservation diagnostics report platform errors or moved reservations; the bounded diagnostic counter is now atomic. These changes collect evidence for the supplied memory crash, without relaxing memory protections or claiming that crash resolved.

## Verification scope

Module-path, save-header disk-full/preservation, patch-selection and utility-cache regression fixtures passed. The path fixture reproduced the old nested-path failure; the disk-full fixture reproduces the ENOSPC write shown in the supplied log. A five-second GTA IV host run passed loaded-module name/path and absent-module checks, launched successfully, and reported 44 refreshed outputs versus 44 submitted swaps. This short host run is not a gameplay or console performance benchmark.

Native compilation and image validation passed (11 mapped sections, five congruent and disjoint loadable segments, all relocation destinations mapped). The console update verified the uploaded mapped/dynamic segments and retained the previous executable. No new-build console gameplay result is claimed.

GTA IV logs showed Unlock FPS applied with VSync off and a later average of 26.8 submitted swaps/s. This build does not promise stable 60 FPS or identify its CPU/GPU bottleneck. Fresh console logs are needed for Halo 3 gameplay, GTA IV heavy scenes and the PuTTY crash, whose build and selected game were not identified in the capture.

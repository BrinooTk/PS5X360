# PS5X360 v0.4.9-preview — loading fixes

## Changes

- ISO format detection now reads candidate volume signatures instead of mapping and walking the entire directory tree. Previously LaunchPath and CreateVfsDevice each performed a complete temporary mount before the final mount. Full directory validation still occurs when mounting the game. This removes redundant loading work; it does not establish the cause of every reported console freeze.
- File signature probing closes files on every return path, uses non-throwing file-size queries, and checks reads/seeks before interpreting their results. The empty-file descriptor leak was reproduced before the fix.
- POSIX mappings with a nonzero offset and default length now expose only the remaining bytes. Read-only mappings validate the requested range. File open/stat/map failures record the error and range for diagnosis. Explicit read/write lengths, used by save-state storage, retain their sizing behavior.
- Native boot logs persist loader phase markers for source classification, device creation, initialization and failures, independently of verbose logging. Existing per-game log paths are retained.
- Crash and thread-probe output writes directly to the boot-log descriptor before the kernel mirror. Signal handlers no longer call the allocating, mutex-protected network logger or wait for a network drain. This addresses a reporting deadlock risk, not the underlying game abort. Crash lines should be collected from boot.log/kernel output rather than relying on TCP output.

## Verification

The offset-to-EOF mapping fixture failed before the fix (8192 reported bytes instead of 4096); the empty-file probe fixture also failed before its fix (two leaked descriptors after two probes). Both now pass. Fixtures cover all five existing ISO partition offsets, mount a small disc containing an ordinary default.xex entry, and check XEX/LIVE signatures and absent files. These are filesystem checks, not game compatibility benchmarks.

Module-path, save-header preservation/disk-full and patch-selection regressions passed. A five-second GTA IV host run passed setup, launch and loaded-module lookup checks, recording 45 refreshed outputs and 45 submitted swaps. This is not a console frame-rate measurement.

Native compilation and image validation passed: 11 mapped sections, five congruent/disjoint loadable segments, and relocation destinations mapped. Matching symbols are retained in `build/symbols/0.4.9-preview`. Gameplay on the console remains unverified.

## Community reports

Investigated sources: [open issues](https://github.com/BrinooTk/PS5X360/issues) and Brino's Place `ps5x360-bugs`. See [the community review](../COMMUNITY_REPORTS_2026-10-04.md).

Forza Horizon 2 logs identify 0.4.6-preview and an abort without a complete stack. Ninja Gaiden 2 captures stop before completed loading. Fresh console tests are still needed for those games, Halo Reach, Banjo, BattleBlock Theater and the other reported stalls. No stable-60-FPS, firmware-wide or gameplay compatibility claim is made by these loading fixes.

# PS5X360 v0.5.0-preview - storage, launch aborts and measurement

Tester build. Game compatibility is still being refined; see the verification limits below.

## Changes

- **Save storage no longer holds caches.** The title's `/download0` is an image of about 321 MiB
  (`download0.dat` measured 336,789,504 bytes on the development console). Shader caches, the
  per-module instruction info cache and the guest `cache:`/`cache0:`/`cache1:` partitions were
  stored there with saves and profiles. Regenerable data now goes to `/app0/cache` when the
  installation folder is writable, and the old `cache` and `utility-cache` folders in the save
  storage are removed at start-up. When `/app0` is not writable the previous layout is kept.
  Every session logs where caches are and how many KiB the save storage holds.
- **Instruction info cache is optional.** `XexInfoCache::Init` called throwing
  `std::filesystem` functions; on the development console a game not started before
  (Dragon Ball: Raging Blast 2) aborted in `create_directories` during `LaunchPath`. The cache is
  skipped with a warning instead.
- **Exceptions at the two boundaries that cannot unwind.** A C++ exception thrown inside a
  kernel export is caught in the export trampoline and returned as `X_STATUS_UNSUCCESSFUL`.
  An exception thrown by `Emulator::LaunchPath` is logged, a note is left for the library and
  the title restarts; the library shows the reason. Boot logs record whether throwing and
  catching works on the console (`BOOT exceptions: thrown and caught` on firmware 13.60).
- **Emulated console settings.** A truncated `xconfig.settings` loaded as zeros and the zero
  screen size divided by zero in `VdQueryVideoMode` (SIGFPE on launch of GTA IV). The file is
  validated on load and saved through a temporary file, with an in-place fallback.
- **Threads and memory.** Guest thread affinity is not applied to host threads (a spinning
  guest thread starved a pinned one). Whole-kernel-page protections hold against 4 KiB commits
  beside them.
- **Measurement.** The guide has "Measure performance (5 s)": per thread, the share of samples
  in generated guest code, in the title and in system libraries, with the commonest places.
  Every 30 samples the game log also records memory-watch protections and faults per second.

## Evidence

- Raging Blast 2 abort: matching-build stack `abort_message` <- `__cxa_throw` <-
  `filesystem::__create_directories` <- `XexInfoCache::Init` <- `XexModule::Precompile` <-
  `Emulator::CompleteLaunch`, on the main thread after `LOAD device ready`. Why the folder could
  not be made was not read from the console; a full save storage is the hypothesis (earlier
  sessions logged errno 28 on save headers and a settings file that could not be saved).
- GTA IV at about 19 swaps/s: the GPU command thread is saturated; guest main and render threads
  spin waiting for it. 6500-7500 kernel protection calls per second at about 40 microseconds
  each and 1000-2000 write faults per second. Watch blocks of 64 KiB were tried and reverted
  (more faults, no gain). No frame-rate improvement is claimed by this build.

## Verification

Native compilation and image validation passed. Symbols are kept in
`build/symbols/0.5.0-preview`.

On the development console (firmware 13.60) the first start of this build logged the cache
relocation (39 and 10 entries removed from the save storage, which then held 85,448 KiB) and
Dragon Ball: Raging Blast 2, which aborted on every attempt with the previous build, launched
and reported 59.0 rendered outputs per second over its first 30 samples (minimum 33). That is
a log reading, not a visual check, and no other game was run with this build. Other firmwares
and installations where `/app0` is read-only are unverified.

## For testers

- Install by replacing the `PPSA50011` folder as before. Saves and profiles are kept; shader
  caches are rebuilt once.
- If a game still fails to open, the library may show the reason after it restarts. Send that
  text together with `boot.log` and the game's log from this version (`tools/Download PS5 logs.bat`).
- Logs from older versions cannot be matched to this build's symbols.

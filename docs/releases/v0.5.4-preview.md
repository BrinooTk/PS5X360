# PS5X360 v0.5.4-preview

- Fixed a POSIX thread lifetime error: dropping the final guest reference could destroy native thread mutexes before exit bookkeeping. Native completion now runs before releasing that reference. The final-owner scenario reproduced a use-after-free before the fix and passes AddressSanitizer after it.
- Saved data, profiles and achievements now use `/data/homebrew/PPSA50011/saves`. On first use, existing `/download0/xbox360ps5/content` data is copied without deleting the original. Existing homebrew saves are never overwritten by an older copy.
- Added **Settings > Saved data**, displaying the actual storage path and game/profile directories. Back up the complete folder with the emulator closed.
- If direct homebrew access is blocked, the installation mount `/app0/saves` is tried. If both locations are inaccessible, the emulator keeps using the original content directory and records the fallback in the game log.
- AutoLog 1.0.8-preview recognizes the Guide's normal return-to-launcher event explicitly. Uploads still require session completion evidence and unchanged files; active gameplay is not uploaded.

This is a test build. The shared thread-lifetime regression and storage migration have been checked on the host. These checks do not certify Witcher 2, Dante's Inferno or Silent Hill Downpour gameplay, nor fix every reported black screen or loading stall. Console regression tests remain required.

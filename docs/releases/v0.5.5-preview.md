# PS5X360 v0.5.5-preview

- The compiled emulator version is visible in the bottom-right corner of the library, settings, saved-data panel and loading screen. The in-game Guide also shows the version. It comes from `VERSION`, rather than a separately maintained UI string.
- Xbox 360 guest `KeBugCheck` failures now record an explicit marker and guest registers, LR, CTR, stack and readable code context before suspending the faulting guest thread. STOP 0 alone is not a root-cause diagnosis.
- Bounded crash-dump address arithmetic prevents a corrupt guest address from wrapping at the 4 GiB boundary.
- AutoLog 1.0.9-preview distinguishes a guest kernel bugcheck from a generic translated guest crash, even when both register-dump and bugcheck markers are present.

This update improves diagnostics. It does not claim to fix every crash, console freeze, graphical error or loading stall. The thread-lifetime fix from v0.5.4 remains in this build. A guest kernel bugcheck and a PS5 kernel panic are different failure classes; whole-console failures need their own evidence.

# PS5X360 v0.5.9 Fix 1 — Displayed version correction

The library and in-game guide now display **PS5X360 v0.5.9**, replacing the inherited
v0.5.8-vulkan.4 footer. This addresses the owner's report that the new release still
showed the previous version name.

Only ten bytes in the existing read-only display-label allocation changed. The
executable was re-signed, without recompiling or relinking the emulator. Code segments,
layout, imports, dynamic tables and all bytes outside this label remain identical
to the working Kinect build used for v0.5.9. The shorter label was checked against
both launcher text-construction paths and the guide's direct text pointer.

This is a version-label correction, not a new performance or compatibility update.
The [v0.5.9 features](https://github.com/BrinooTk/PS5X360/releases/tag/v0.5.9) remain:
Vulkan cache/scheduling improvements, native disc switching and evolving optional
smartphone Kinect input with camera calibration. Kinect remains in testing and is
not guaranteed to work 100%; full multi-disc campaign transitions need broader testing.

## Install

Close PS5X360, then extract PPSA50011.zip into `/data/homebrew/`. The executable should
be `/data/homebrew/PPSA50011/eboot.bin`. Preserve games, saves, profiles, settings, logs
and your local phone-camera configuration/certificate. No new camera or AutoLog setup
is needed if yours already works; those two downloads are unchanged.

GitHub made v0.5.9 immutable, so this correction is a separate release. Package
VERSION is `0.5.9-fix1`; the visible product label is `PS5X360 v0.5.9`.
Some retained diagnostic strings still identify the original internal build for
provenance; the correction specifically addresses the library and guide footer.

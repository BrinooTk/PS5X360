# PS5X360 v0.5.9

## Performance and compatibility

- Updated Vulkan pipeline/cache handling and command scheduling, including targeted
  waits and cache maintenance. Performance still depends on the game and scene.
- General PS5 socket error translation fixes, used to get Modern Warfare 3 past its
  previous startup stall, plus retained Vulkan texture and shader corrections.
- Remaining texture, lighting and loading problems are still under investigation.
  This release does not promise stable 60 FPS or full-library compatibility.

## Games with two or more discs

- Native disc switching validates the requested disc before changing the mount and
  preserves existing open file handles. It does not restart the campaign.
- Keep each complete extracted disc in its own folder:

```text
assets/roms/Max Payne 3/Disc 1/default.xex
assets/roms/Max Payne 3/Disc 2/default.xex
```

Start Disc 1. The runtime can locate matching media when the game requests another
disc. A `discs.m3u` beside the media can list relative XEX or ISO/ZAR paths explicitly.
Automatic matching also recognizes appropriately named disc images. Invalid,
missing or ambiguous media is rejected. Install-only discs require their game's
installation workflow; this is not automatic merging of their data.

Full campaign disc transitions still need broader PS5 testing. The separate grouped
library/confirmation-dialog candidate is not part of this published executable.

## Smartphone Kinect is evolving

- Dragon Ball Z for Kinect now has a targeted estimated hand adapter for its menu
  gestures. Identification and menu interaction were reported working by the owner.
- The PS5 QR settings page includes a phone camera entry.
- The updated camera page adds optional calibration, estimated forward/backward and
  lateral body movement, optional stabilization, and a return to original mapping.
- Calibration requires a fixed, level camera, entered body height/starting distance,
  and at least two seconds standing still with the whole body visible.

**Smartphone Kinect remains in testing and is not guaranteed to work 100%.**
An RGB camera estimates depth; it does not measure a Kinect depth image. Navigation
working in one game does not establish combat gestures or support for other games.
The latest calibration passed host tests but still needs real-camera gameplay testing.

Download `Kinect-Phone.zip` for the optional camera relay. A PC on the same LAN must
remain running; video stays on the camera device and only estimated joints are sent
to the PS5. Each tester must configure their own LAN address and trusted HTTPS
certificate. The package contains no maintainer certificate or private key.

## Install / update

1. Close PS5X360. Extract `PPSA50011.zip` into `/data/homebrew/`, giving
   `/data/homebrew/PPSA50011/eboot.bin` without a second nested title folder.
2. Replace application files while preserving ROMs, saves, profiles, settings, logs
   and any locally configured `phone-camera.conf` and phone CA certificate.
3. Keep Vulkan selected. OpenGL is not a supported gameplay renderer in this build.
4. Optional diagnostics: load `PS5X360-AutoLog-v1.0.9-preview.elf` through your payload
   loader. AutoLog remains optional and unchanged in this release.

# PS5X360 v1.0.0

Everything since v0.6.0: the newest Xenia Canary core, a new home screen in the manner of the
Xbox 360 dashboard, the games' own system windows (sign-in, saves, messages) on screen, online
play over the internet (experimental) and System Link, and fixes for games that ignored the
controller or stopped at loading. Compatibility keeps improving, but results depend on the game,
firmware and homebrew setup.

## New home screen

- A home in the manner of the Kinect-era Xbox 360 dashboard: channels **Início**,
  **Configurações** and **Online** (up and down), slots that turn away in perspective (left and
  right), and a row that tips over when the channel changes.
- **The game played last comes first**, as a disc in the tray: "Jogar *game*" over the game's own
  Marketplace picture and icon, downloaded once from Microsoft's image server by title ID and kept
  in `PPSA50011/game-art`. Then the game library, the player and the achievements.
- **Game library:** the covers on a shelf, only the cover, with an opening animation.
- **The whole emulator** follows the new look: light grey background, the dashboard's green,
  PlayStation button shapes, and the guide over a running game restyled, with a 3D unfold.
- PS5X360's own pictures throughout (`assets/skin`); any of them can be replaced with a file of the
  same name in `PPSA50011/skin`. `ui-classic.on` in the title folder brings back the old shelf.
- **Your own Xbox 360 dashboard:** a `dash.xex` copied to `PPSA50011/dashboard` can be opened from
  Configurações > Painel original and starts the library's games. It is your file, read on your
  console; nothing of it is in this package.

## Games' system windows

The windows a game opens through the console — who is playing, where to save, messages with
buttons, the keyboard — now show on screen and answer to the controller, as Xenia on a computer
does. Before, they answered by themselves: **Bayonetta**'s "No active profile" message signed in
nobody and asked again forever, so its title screen never took START.

## Controller

- Games that wait for "any controller" were told no controller was connected when no key was
  pressed. Bayonetta now plays; Crash: Mind over Mutant and Rayman Legends reported the same
  symptom and were not retested.
- A vibration request that the console refuses no longer marks the pad as disconnected (#46).

## Online play and System Link (experimental)

- Xenia Canary netplay (AdrianCassar) is part of the core: **Online** channel > "Online:
  DESLIGADO / LIGADO" (X switches; the emulator restarts). It uses the public Xenia server.
  A profile that signs in while online becomes a Live profile by itself, keeping saves and
  achievements. When a game closes, its online sessions are removed and router ports closed.
- **System Link** (consoles on the same network) is the other slot of the channel.
- **Status:** the connection to the Xenia server is still being brought up on the PS5. The
  emulator writes a network self-test to its log at each start in online mode; if a game still
  says you must sign in to Xbox LIVE, send that log.
- The PS5 refuses some calls the network libraries use (name lookup, some C library functions);
  PS5X360 answers them itself.

## Core and compatibility

- **Xenia Canary e6cd2e4** (2026-10-20), the newest at release time, with all of c28af11's
  changes before it.
- `xstorage:` is mounted as on a computer; the guide over a game tells the game the system
  interface is showing (most pause, as under the Xbox guide).
- Per-game core settings taken from Xenia's compatibility reports (for example WWE's match start).
- **WWE:** a wait for a wake-up that never came kept the loading screen up.
- Graphics presets for about 220 games that read back the GPU's pictures, and a faster path that
  copies small pictures back without waiting (dark or flashing scenery).

## Tools

- `PS5X360-Instalar-DLC-e-Updates` (from the maintainer, not in this package): drag a folder of
  Xbox 360 DLC and title updates onto it on a PC and they are sent to the right place over FTP.

## Known problems

- **Online:** see above; not yet confirmed on a console.
- **Need for Speed Most Wanted (2012)** stops at the start of driving: a known Xenia Canary
  crash for this game (game-compatibility #1054).
- **Xbox avatars** are not drawn: Xenia has no avatar system yet.
- Kinect remains experimental.
